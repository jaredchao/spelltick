# 设计稿说明

这个目录里的 `.dc.html` 是设计稿的源文件，是**视觉参考，不是可以直接用的代码**。

- 每个文件是一张画板。只需要看 `<x-dc>` 标签内的 HTML 和内联样式：布局、间距、颜色、字号、文案都在里面
- `<script type="text/x-dc">` 是设计工具的脚本，`{{accent}}` 这类占位符就是皮肤的强调色。实现时忽略这部分
- 颜色和字体以 `skins.json` 为准；设计稿和 `skins.json` 不一致时，以 `skins.json` 为准

| 文件 | 内容 |
|---|---|
| `Main.dc.html` | 皮肤 A · 原生极简：收起 / 答题 / 反馈 三个状态 |
| `Terminal.dc.html` | 皮肤 B · 终端代码：同上 |
| `Paper.dc.html` | 皮肤 C · 纸感词卡：同上 |
| `SettingsA.dc.html` | 皮肤 A 下的设置窗口「出题」分页 + 托盘菜单 |
| `SettingsB.dc.html` | 皮肤 B 下的设置窗口「词库与 AI」分页 + 托盘菜单 |
| `SettingsC.dc.html` | 皮肤 C 下的设置窗口「通用」分页 + 托盘菜单 |

三个设置分页分别画在三套皮肤里，只是为了展示全部设置项。实际上**每套皮肤都有全部四个分页**，结构完全相同。

托盘菜单 MVP 用系统原生菜单，设计稿里的皮肤化样式先不实现（见 SPEC 第 10 节）。
