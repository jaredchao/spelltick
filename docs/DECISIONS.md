## M3 · 调度与免打扰

| # | 问题 | 决定 |
|---|---|---|
| 3.1 | 调度器放在哪里 | Rust 后台线程，每秒检查一次。弹窗隐藏时 WebView 计时器可能被系统节流，放前端不可靠。SPEC 要求的两条命令 `is_fullscreen_app_active`、`seconds_since_last_input` 仍然暴露给前端 |
| 3.2 | 设置怎么存 | `settings` 表里一个键 `app`，值是完整 JSON；缺字段时用默认值，加字段不需要迁移 |
| 3.3 | 间隔从什么时候算 | 从上一次弹窗关闭时算（含手动按 ⌘⇧E 出的题）；弹出那一刻先排一个临时时间，防止没出题时调度卡住 |
| 3.4 | 工作时段之外 | 下一次 = 下个工作时段开始 + 一个间隔；托盘倒计时按这个时间显示 |
| 3.5 | 暂停结束后 | 下一次 = 恢复时刻 + 一个间隔，不在恢复那一刻立即弹 |
| 3.6 | 「今天不再弹」 | 到第二天工作时段开始再恢复（关闭工作时段时是第二天 0 点） |
| 3.7 | 暂停和「今天不再弹」重启后是否保留 | 不保留，只存在内存里 |
| 3.8 | 超时重出 | peek 超时后 5–10 分钟重出同一条；如果到时正好在暂停、免打扰时段或工作时段外，这次重出取消 |
| 3.9 | 全屏判断（macOS） | 取最前面一个普通窗口（layer 0，排除本应用），尺寸等于任意一块显示器时视为全屏，不需要额外权限 |
| 3.10 | 打字判断 | 只读系统空闲秒数，不读按键内容；小于 3 秒算正在打字 |
| 3.11 | 终端皮肤托盘倒计时 | 文案模板用皮肤里的 `trayNext`，时间统一格式成「5 分钟」，所以终端皮肤显示 `next in ~5 分钟` |
| 3.12 | 托盘状态行刷新 | 倒计时每秒检查一次，文字变了才更新；今日统计每 10 秒查一次数据库 |

## M4 · 设置页、导入导出、皮肤

| # | 问题 | 决定 |
|---|---|---|
| 4.1 | `skins.json` 缺的结构 | 补了两个 token：`--radius-peek`（peek 圆角）、`--radius-icon`（发音按钮圆角），和一个布局开关 `peekMarker`（`dot` / `chevron` / `tile`）。三套皮肤都有值 |
| 4.2 | 设计稿里随皮肤变化、但 `copy` 里没有的文字 | 不做。例如终端皮肤的 `$ define`、`general / quiz` 英文导航，纸感皮肤的 `No. 128`、「最后两个字母顺序反了」。要加的话需要先在 `copy` 里加键 |
| 4.3 | 设置的保存方式 | 改动立即保存，没有「保存」按钮；保存后广播给弹窗和托盘 |
| 4.4 | 设置窗口标题栏 | 用系统原生标题栏，不画设计稿里的自绘标题栏 |
| 4.5 | 快捷键录制 | 点击按钮后按组合键；必须带 ⌘ / Ctrl 或 Alt，加一个字母、数字、F 键或空格；Esc 取消。两个快捷键相同也显示红字 |
| 4.6 | 开机自启 | 只在正式包里生效；开发版不注册登录项 |
| 4.7 | 导入 CSV 的表头 | 第一行第一列是「英文 / term / word / english」时当表头跳过 |
| 4.8 | 导入 CSV 的重复词 | 同一文件里重复的词（不区分大小写）保留第一条，预览里单独提示「另有 N 行重复」，不算格式错误 |
| 4.9 | 导入 CSV 的格式错误 | 少于 2 列、多于 3 列、英文或释义为空、第一列不含英文字母或含中文、引号未闭合 |
| 4.10 | 可以删除的词库 | 导入的词库和「我的生词本」都能删，内置词库不能删 |
| 4.11 | 学习进度文件内容 | 自建词库（含条目）、所有复习记录、设置；内置词库只记启用状态。不含答题流水（`attempts`），所以导入后「今日题数」从零开始 |
| 4.12 | 学习进度导入 | 先清空自建词库、复习记录、答题流水，再写入文件内容；用系统确认框提示「会覆盖当前进度」 |
| 4.13 | 交还焦点（M1 遗留） | 弹窗获取焦点前记下最前面的应用，收起时重新激活它；记不到时才隐藏本应用，且设置窗口开着时不隐藏 |
| 4.14 | 出题页增加的项 | 设计稿没画「每天新内容上限」和「显示首字母」，按 SPEC 第 11 节加在「出题内容」末尾 |
| 4.15 | 视觉预览页 | `preview.html` 只在开发时用，用 mock 数据渲染弹窗三种状态和设置页，不进正式包 |

## M5 · AI 与生词

| # | 问题 | 决定 |
|---|---|---|
| 5.1 | AI 请求怎么发 | 前端调用 `tauri-plugin-http` 的 `fetch`，写法和浏览器 fetch 一样，但请求从 Rust 侧发出，不受 CORS 限制（DeepSeek 等接口不一定允许 WebView 跨域） |
| 5.2 | API Key 的流向 | 只存系统钥匙串；需要请求时前端临时取一次，不写数据库、设置文件、导出文件和日志。日志写入前还会把形如 `sk-…` 的词替换掉 |
| 5.3 | 「没配置时隐藏 AI」的范围 | 弹窗、反馈卡、加入生词窗口里的 AI 元素全部隐藏；设置页的 Base URL / Key / 模型输入框必须一直显示（否则没法配置），三个功能开关在配置完整后才显示 |
| 5.4 | 生成例句的时机 | 一道题出现时，如果这条内容没有例句，后台生成一句写进数据库（`example_ai = 1`），下次出题才用到；同一次运行里同一条只请求一次 |
| 5.5 | 答错讲解 | 只在答错时请求；先显示「讲解生成中…」，失败或超时就整行隐藏；超过 60 字截断加「…」 |
| 5.6 | 错词出新题 | 选题落到「最近答错」且是单词时，先生成一个新例句，用它出挖空题；这个例句不写进数据库；生成失败就按普通方式出题 |
| 5.7 | 读取选中文字 | 等用户松开快捷键的修饰键，模拟一次 ⌘C / Ctrl+C，读剪贴板，再把原来的剪贴板文字放回去。剪贴板里原来是图片或文件时无法还原 |
| 5.8 | 辅助功能权限 | 第一次按加入生词快捷键时才请求；没有权限时窗口顶部给出说明和「打开系统设置」按钮，同时允许手动输入 |
| 5.9 | 选中内容过长 | 只取第一行非空文字，最多 200 个字符 |
| 5.10 | 加入生词窗口 | 居中显示、置顶、获取焦点（用户主动触发）；Enter 保存、Esc 取消；关闭后把焦点还给之前的应用 |
| 5.11 | 皮肤里的 AI 标签 | `copy` 新增 `aiLabel`：原生「AI」、终端「# ai:」、纸感「AI 小记」 |
